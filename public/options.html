TrueDiff

See the real size of a pull request without the tests, and mark the noise as viewed in one click.

1. Connect GitHub

TrueDiff reads PR file lists and marks files as viewed through the GitHub API, using your own token. The token stays on this computer (Chrome's extension storage, which github.com pages can't read) and is only ever sent to api.github.com. The only thing TrueDiff ever changes on GitHub is the “Viewed” tick on files.

How do I create a token?

Safest: fine-grained token

  1. Create a fine-grained token. It expires in 90 days and can only touch pull requests.
  2. Resource owner: your organization. Repository access: All repositories (or just the ones you review).
  3. Permissions → Pull requests: Read and write (marking a file viewed is a write). Leave everything else off.
  4. Some orgs must approve fine-grained tokens first. Until then the token can only read public repos.

If fine-grained doesn’t work: classic token

  1. Create a classic token with only the repo scope (pre-selected). Tick nothing else.
  2. Pick an expiry (90 days is sensible), click Generate token and paste it above.
  3. If your org uses single sign-on: on the tokens page click Configure SSO → Authorize next to your org.
  4. Note: repo is broad (it could also push code), so keep this token for TrueDiff only.

2. What counts as noise

Noise is left out of the real size, and it's what the Mark noise files viewed button marks.

Pattern syntax
  • tests/: a trailing slash means "everything inside any folder called tests".
  • *.test.*: no slash means "any file with this name, in any folder".
  • src/legacy/**/*.js: * stays inside one folder, ** crosses folders.
  • /scripts/: a leading slash anchors the pattern to the repo root.
  • {a,b} means either, ? one character, [0-9] a character range. Matching is case-sensitive.
  • Lines starting with # are comments.
