# TrueDiff brand

The mark is **the pull-request pair**: a pull-request graph redrawn in plus and minus. A main line and a returning
branch borrow GitHub's pull-request shape, and the two large nodes carry a plus and a minus. It was designed in
Figma Make.

| File | Use it for |
| --- | --- |
| `logo.svg` / `logo-dark.svg` | The mark with the name, on light / dark backgrounds |
| `mark.svg` / `mark-dark.svg` | The mark alone, on light / dark backgrounds |
| `icon.svg` | The extension icon: the mark on a cream tile. `npm run icons` renders `public/icons/` from it |

The PR strip on GitHub draws the mark in one colour (`brandMark()` in `src/content/dom.ts`).

**Colours:** ink `#283b33` (`#edf3ec` on dark), copper `#ba663f`, tile cream `#f8f0e9`.
**Name:** Manrope at weight 750 with tight letter-spacing, outlined to paths in the SVGs, so they need no font.
Manrope is by The Manrope Project Authors, under the [SIL Open Font License](https://github.com/googlefonts/manrope).
